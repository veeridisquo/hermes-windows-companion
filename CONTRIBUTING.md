# Contributing

Thank you for helping improve Hermes Windows Companion.

## Before opening an issue

- Confirm the problem still occurs with the latest `main` branch and a supported Hermes Agent version.
- Search existing issues for the same behavior.
- Remove credentials, tokens, private logs, usernames, and local filesystem paths from anything you share.
- Report security problems privately according to [SECURITY.md](SECURITY.md).

## Pull requests

Keep changes focused and explain the user-visible reason for them. Test on Windows 10 or Windows 11 with Windows PowerShell 5.1 or newer. In the pull request, describe what you tested and any behavior you could not verify.

Do not commit generated logs, local configuration, credentials, signing keys, or packaged copies of Hermes Agent.
