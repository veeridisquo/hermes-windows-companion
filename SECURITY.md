# Security policy

## Supported version

Security fixes are made on the `main` branch. Please reproduce an issue against the latest commit before reporting it when practical.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, tokens, private logs, or personal information in an issue.

Use GitHub's [private vulnerability reporting](https://github.com/veeridisquo/hermes-windows-companion/security/advisories/new). Include the affected version, impact, reproduction steps, and any suggested remediation.

If private reporting is unavailable, open a public issue containing no sensitive details and ask the maintainer to establish a private channel.

## Scope

Reports about Hermes Agent itself should be sent to the [Hermes Agent security policy](https://github.com/NousResearch/hermes-agent/security/policy).
